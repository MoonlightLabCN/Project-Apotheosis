    Known limitation (0.2.0)

    This port runs ONE live Page plus snapshots of the other tabs. There is no second
Page for window.open() to return a WindowProxy for, so:

  · window.open() returns null
  · the new tab has no opener  (equivalent to rel="noopener")
  · window.opener / cross-tab postMessage do not work

Cookies and storage ARE shared process-wide, so the usual OAuth fallback — log in
in the new tab, come back, reload — still works. Returning a pointer to a Page
that does not exist would be a use-after-free, so null is the correct answer here
rather than a convenient lie.
